База даних для кондитерської майстерні що виготовляє торти.                                
Виконані лабораторні роботи 1,2,3,4,5 з курсу "Організація баз даних"
Предметна область:
Інформаційна система призначена для автоматизації роботи кондитерської майстерні, яка виконує індивідуальні замовлення на виготовлення тортів.
Метою системи є автоматизація процесів обліку та управління діяльністю кондитерської майстерні, оптимізація роботи персоналу та контроль виконання замовлень. 
Система забезпечує облік клієнтів, замовлень, виробів, кондитерів, а також інгредієнтів, необхідних для виготовлення продукції. 
Вона охоплює процеси від оформлення замовлення клієнтом до його виконання та оплати.
